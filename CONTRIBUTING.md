# Contributing to Omnora

Thank you for your interest in Omnora.

## Current contribution policy

Omnora is planned as an AGPL community project with a separate proprietary commercial licensing option. That model requires the project to hold sufficient rights to offer accepted contributions under both licenses.

A legal commercial licensor and contributor agreement counterparty have not yet been designated. Therefore, the repository does not currently accept external code, documentation, translation, design asset, or other copyright-bearing pull requests.

You may still:

- report reproducible defects;
- propose features and use cases;
- provide security reports through the repository's published security channel once available;
- discuss architecture and interoperability without submitting copyrighted implementation material.

Do not include patches, source code, design assets, or substantial copied text in an issue while this restriction is active.

## Future contributor agreement

Before external contributions open, the project will publish a contributor license agreement reviewed by qualified counsel. It will identify the legal counterparty and grant the rights required to distribute accepted contributions under both AGPL and proprietary commercial terms while allowing contributors to retain ownership of their work.

A Developer Certificate of Origin alone is not sufficient for Omnora's planned dual-license model because it does not grant the project a general right to relicense contributions under proprietary terms.

## Development process

Build instructions, coding standards, test requirements, security reporting instructions, and pull request checks will be added with the first implementation plan and project scaffold.
