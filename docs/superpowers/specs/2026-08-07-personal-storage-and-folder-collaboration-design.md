# 个人存储、直接挂载与文件夹协作设计

状态：已被取代
日期：2026-08-07

> 本文关于个人 Space、每账号独立默认挂载、禁止分享个人根目录和 Space ACL 的设计，已被[账号、挂载与内容授权设计](2026-08-08-account-mount-access-design.md)取代，不得再作为实施依据。

## 目标

将“空间”恢复为权限与内容组织边界，不再让外部 NAS 插槽隐式改变真实目录结构；为每个成员提供系统管理的个人隔离目录，并让成员可以把个人空间中的一个文件夹直接授权给其他登录成员协作。

## 概念与范围

| 对象 | 含义 | 真实文件系统行为 |
| --- | --- | --- |
| 个人空间 | 成员自己的逻辑内容与权限范围 | 新成员自动获得一个系统管理的个人目录与默认托管挂载 |
| 共享空间 | 管理员创建的团队逻辑空间 | 管理员选择并挂载一个或多个独立真实目录 |
| 外部挂载 | NAS 上已存在或由管理员指定的目录 | 精确注册所选目录；绝不在目录内创建空间 ID 子目录 |
| 插槽 | 容器可访问外部 NAS 路径的 allowlist | 只限制可选择路径，不分配目录、不实现空间隔离 |
| 文件夹协作 | 个人空间目录的成员级授权引用 | 指向原目录，不复制、不移动、不创建新空间或挂载 |

## 存储规则

1. 新增 `OMNORA_PERSONAL_STORAGE_DIR`，默认 `/var/lib/omnora/personal`。它必须位于持久化数据卷中，但与 SQLite 数据库文件分开。
2. 创建账户时，系统为其创建 `<personal-root>/<account-id>/`，并在其个人空间下登记一个 `managed`、`read_write` 的默认挂载。
3. 默认个人挂载是系统资源；管理员不能随意把它改指向其他目录或删除。若历史账户未完成创建，则只允许明确的管理员修复流程补齐，不在启动时批量创建目录。
4. 选择 `/mnt/omnora/slotN` 或其更深层路径时，挂载根就是所选路径本身。现有文件立即可见；路径重叠、身份漂移、只读与符号链接规则继续 fail-closed。

## 文件夹协作

协作目录只能来自当前成员自己拥有的个人空间，且必须是已存在的非根目录。创建者可为一个或多个活跃成员分别授予：

- `viewer`：浏览、预览与下载；
- `editor`：在授权根目录内新建、上传、改名、移动和删除子项。

默认权限为 `viewer`。协作者不能浏览授权根的父目录、兄弟目录或个人空间其他内容，不能改名、移动或删除协作根本身，也不能使用回收站、全空间搜索、跨挂载移动或 AI Token 访问该授权。

协作记录独立于匿名公开分享：不使用 URL fragment、密码、有效期或访问次数。源目录被所有者移动或删除、源挂载失效、接收者账号停用或授权撤销时，协作访问立即失效。

## 数据与接口

新增目录协作记录，保存来源个人空间/挂载、根相对路径、授权人、接收人、`viewer|editor`、撤销时间与审计信息。相同接收者的重叠授权在创建时拒绝，避免父目录和子目录不同权限的歧义。

成员 API：

```text
GET    /api/v1/folder-collaborations?direction=outgoing|incoming
POST   /api/v1/folder-collaborations
PATCH  /api/v1/folder-collaborations/{id}
DELETE /api/v1/folder-collaborations/{id}
```

收到的协作记录带来源空间、挂载和目录边界。成员端打开后继续使用文件 API；统一访问守卫以协作记录补充普通空间 ACL，并对每一次读写重验授权根、挂载模式、符号链接与挂载身份。

## 成员端

现有“分享”Tab 改名为“分享与协作”，分为两个独立区块：

1. 我的分享：保留现有匿名公开链接的创建、查看、撤销与统计。
2. 与我共享：显示成员协作文件夹、来源人、权限、状态与“打开”入口；默认只读，编辑权限明确标识。

本地开发提供仅开发环境可访问的 mock 预览，展示一条只读和一条可编辑协作记录；它只用于验证 UI，不代替真实 API 授权测试。

## 验收

- 注册插槽根目录不会创建 `<space-id>` 子目录，且已有根目录内容可见。
- 新成员具有位于个人存储根下的默认个人挂载；历史账户可安全补齐。
- 目录协作者只能访问授权根及其子项；`viewer` 无法写入，`editor` 不能操作协作根或越出边界。
- 源目录移动/删除、撤销、账号停用、只读与挂载不可用均阻断协作访问。
- 匿名公开分享、共享空间 ACL、挂载身份验证与现有文件操作回归不变。
