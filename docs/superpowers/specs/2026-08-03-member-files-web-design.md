# Omnora 成员网盘文件页设计

日期：2026-08-03

## 目标

将公网根路径从“NAS Console Preview”替换为实际成员文件工作区。该工作区默认中文，支持中英切换，并只展示成员完成文件任务所需的内容。

## 入口与权限

- `/` 和 `/app/` 是成员 Web，受 `member_web` 路由组保护；关闭该路由组时必须返回 `route_group_disabled`，不能回退到 SPA。
- `/admin/` 保持独立且受 `admin_web` 路由组保护。成员网页面不显示管理台切换器、挂载注册、索引调度、审计或 Token 治理。
- `/share/` 保持独立且受 `share` 路由组保护。分享页面不复用成员空间导航。
- 静态资源可被三个入口加载，但不能包含会话、密码、TOTP、分享秘密或 Token。

## 成员文件页

页面使用紧凑文件管理器布局：

- 顶栏：Omnora 标识、当前空间搜索、中文/EN 切换和账户菜单。
- 左栏：我的文件、搜索、传输、共享入口；当前可访问空间与挂载；当前挂载只读状态。
- 主区：面包屑、上传、新建文件夹、下载、列表/网格切换、真实目录列表；排序作为后续体验增强，不作为首版验收项。
- 底部传输条：显示每个上传的上传、完成、失败和取消状态；刷新后从浏览器本地恢复未完成会话并调用上传状态接口继续。排队状态可在组件测试覆盖，不作为独立发布阻断专项。

任何在首版没有对应后端语义的命令不显示为可用操作。只读挂载显示原因并禁用上传和新建文件夹。

## 真实接口与状态

- 会话：`GET/POST /api/v1/auth/session`。
- 空间、挂载和目录：`GET /api/v1/spaces`、`GET /api/v1/spaces/{spaceId}/mounts`、`GET .../children?path=`。
- 上传：创建会话、读取状态、分片上传、完成、取消五个既有端点。前端按服务端返回的 `partSize` 分片，不使用演示数据。
- 下载：文件行使用同源下载 URL；后端保持 `Accept-Ranges`、`ETag` 和单段 `Range` 语义。
- 搜索：使用当前空间的索引结果，并明确展示未索引或不可搜索的挂载。
- 新建文件夹：新增一个受 editor 权限、挂载身份复核和安全相对路径约束的端点。

## 文件系统边界

挂载根身份复核继续作为每次文件操作的前置条件。目录浏览、下载、上传和新建目录统一使用 Go 1.26 `os.Root` 访问挂载目录，拒绝相对路径逃逸及指向挂载外的符号链接。前端仅显示后端确认的目录项，不根据字符串路径推断权限。

## 语言

`zh-CN` 是无本地偏好时的默认语言。用户选择写入 `localStorage`，同一个应用内的成员页面在刷新后保持选择。所有新成员端 UI 文案由明确的中英文词典提供，错误码保持后端原样并映射为可理解的界面文本。

## 验收

1. 未启用 `member_web` 时，`/` 和 `/app/` 都不能返回成员 SPA。
2. 已登录成员仅能看到自己有 ACL 的空间与挂载，目录列表来自真实接口，不存在 mock 回退。
3. 文件夹可打开且面包屑更新；普通文件可触发浏览器下载；Range 响应仍返回 `206` 和正确 `Content-Range`。
4. 大文件上传可取消、重试和刷新后续传；只读挂载不能创建上传会话或目录。
5. 任何中间层符号链接都不能用于浏览、下载、上传目标或创建目录。
6. 桌面与窄屏下，中文和英文文案均不溢出；默认显示中文。
