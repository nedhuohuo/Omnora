# 初始管理员界面简化设计

## 目标

移除管理端表格中醒目的“初始管理员（受保护）”标记，以普通表格内容表达权限和可用操作，同时完整保留现有初始管理员保护能力。

## 界面行为

### 空间成员

- 初始管理员的“权限”列显示“管理员”。
- 初始管理员的“操作”列显示 `--`。
- 其他成员继续使用现有权限下拉框和移除按钮。

### 成员管理

- 不再显示“初始管理员（受保护）”标记。
- 初始管理员不显示不可执行的停用按钮。
- 保留“撤销全部会话”按钮，因为该操作仍然合法。
- 其他账号继续显示现有停用或恢复按钮。

## 实现边界

- 仅修改 `web/src/member/AdminPanels.tsx` 的条件渲染，并删除 `web/src/member/i18n.ts` 中不再使用的中英文保护标记文案。
- 继续使用用户和空间成员响应中的 `protected` 字段判断是否隐藏非法操作。
- 不修改 API 类型、OpenAPI、后端保护、数据库状态或 `.member-readonly` 公共样式。
- 不全局改写普通空间角色名称，避免影响其他成员的权限下拉框。

## 数据与错误处理

数据流和请求行为保持不变。后端继续拒绝停用初始管理员、修改其空间权限或将其移出空间，并返回现有 `409 initial_admin_protected` 错误。前端通过 `protected` 分支避免发起这些无效请求。

## 验证

- 运行前端 Vitest 测试，确认中英文文案结构和现有逻辑未回归。
- 运行前端生产构建，确认 TypeScript 与 Vite 构建通过。
- 运行初始管理员后端定向测试，确认视觉调整未削弱保护契约。
- 检查最终差异，确认只涉及设计范围内的前端渲染、无用文案清理和相应测试。
