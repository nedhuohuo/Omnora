# Omnora 第一版验收标准

状态：第一版发布门槛
日期：2026-08-02

以下条件全部通过后，第一版才可以标记为可发布。详细业务和安全语义分别以[产品需求](../requirements/product-requirements.md)、[领域模型](../design/domain-model.md)、[技术架构](../design/architecture.md)和[安全模型](../security/security-model.md)为准。

## 1. 功能验收

- 管理员可以创建成员、个人空间、共享空间，并为一个空间添加多个挂载。
- 添加挂载时可以独立选择只读/读写和加入索引/不加入索引。
- 不加入索引的挂载仍可浏览和操作；全局搜索排除该挂载并明确提示。
- `viewer`、`editor`、`manager` 的行为与权限矩阵一致；仅 `manager` 可创建分享。
- 支持分片上传、断点续传、Range 下载、复制、移动、改名和批量操作。
- 托管挂载支持回收站恢复；外部读写挂载永久删除前明确二次确认；外部只读挂载拒绝全部写操作。
- 跨挂载复制和移动具备成功、失败、重试和人工清理路径；移动源端要求 `editor+` 且可写。
- 图片、PDF、文本、Markdown 和浏览器原生音视频按设计预览；Office 文件始终走下载。
- REST 与 MCP 提供已定义的首版能力，并与 Web 使用相同授权结果。

## 2. 空间与分享验收

- 无 ACL 的管理员无法浏览、搜索、预览、下载或修改成员个人空间内容。
- 个人空间应急访问要求管理员重新认证、填写原因并选择目标空间；只授予最长一小时的临时 `viewer` 权限，到期自动失效并完整审计。
- Omnora 内部同挂载移动后分享保持有效。
- 跨挂载移动、外部移动、删除、替换对象或创建者失去 `manager` 后，原分享失效。
- 分享密码、有效期、访问次数、下载次数和撤销立即生效。
- 高并发请求不能突破分享次数上限；Range 和取消下载的计数策略与安全模型一致。

## 3. 凭证与权限验收

- 有效权限严格等于账号状态、空间 ACL、Token scope、目录边界和挂载模式的交集。
- 成员只能管理自己的 Token；管理员只能查看元数据和撤销，不能读取明文。
- 账号禁用、ACL 降级、Token 或分享撤销后，活动 MCP 会话、上传会话和短期下载地址立即失去对应权限。
- 两个并发初始化请求只能有一个成功；系统没有默认账号或默认密码。
- 管理员锁定恢复不会重新开放网络初始化入口，并使旧会话和旧 TOTP 失效。

## 4. 文件系统安全验收

- 路径穿越、绝对路径、符号链接逃逸、magic link、挂载点越界和大小写混淆测试均被拒绝。
- 在权限检查与实际打开之间替换文件、符号链接、目录或挂载点时，Web、REST、MCP 和分享入口均不能越界。
- 用户不能创建、覆盖、移动、分享或通过 AI 访问 `.omnora` 保留命名空间。
- 只读挂载即使应用配置错误或请求来自管理员也不能写入。
- HTML、SVG、XML、伪造 MIME 和未知主动内容不能在认证应用源执行脚本或读取 Cookie。
- 文件名不能通过响应头注入 CR/LF；未知格式默认作为附件下载。

## 5. 网络验收

- 局域网 HTTP 只有在管理员显式启用并配置 LAN CIDR 后可用，界面持续提示风险。
- 公网 Web、分享、REST 和 MCP 拒绝无 HTTPS 的配置或请求。
- 未受信代理提交的 `X-Forwarded-For`、`Forwarded` 和外部协议头被忽略。
- 合法代理 CIDR、Host、Origin、CORS 和 MCP Streamable HTTP Origin 校验通过正反向测试。
- 管理端、成员 Web、分享、REST、MCP 和 OpenAPI 可以独立控制是否暴露。

## 6. 索引与性能验收

- 使用百万级合成元数据验证 keyset 分页和文件名搜索，不使用深层 `OFFSET`。
- 全量扫描单并发、可暂停、可续跑、批次让出，不阻塞高优先级后台任务。
- 文件事件不可用时，对账最终收敛；连续两次全量对账不会重叠。
- 索引中的失效条目不能绕过实时文件系统复核。
- 在极空间 8 GB RAM 环境，空闲内存处于 100 至 300 MB 目标范围，普通操作不超过 500 MB。
- 大文件上传、下载和跨挂载复制使用固定缓冲区，内存不随文件大小线性增长。

## 7. SQLite 与可靠性验收

- WAL 检查点、并发读取、受控单写入和数据库忙状态不会无限阻塞请求。
- 扫描、上传、跨挂载移动和索引更新期间重启 Omnora，任务能够恢复到一致状态。
- 上传配额在并发场景不会超卖；异常退出后的临时分片可以安全回收。
- 挂载离线、权限变化、磁盘不足和外部文件变化均产生明确状态，不误删有效内容。
- 使用 SQLite Online Backup API 或等价方案完成备份和恢复演练，并通过完整性校验。
- 从旧备份恢复后，旧会话、Token、公开分享、分享派生会话、下载票据和上传会话均不可继续使用；成员首次登录前必须重设密码。
- 外部挂载在恢复后未经重新验证不能自动启用。

## 8. 审计与发布验收

- 登录、权限、应急访问、挂载、写操作、分享、Token、REST/MCP 敏感操作和恢复均进入审计。
- 审计日志不包含密码、Token 明文、分享密钥、文件正文或未脱敏的分享 URL。
- 达到审计保留上限或磁盘安全水位时行为明确，不能静默丢弃关键安全事件。
- `linux/amd64` 和 `linux/arm64` 镜像均构建通过。
- 极空间和普通 Linux Docker Compose 各完成一次部署验证。
- 首个公开源码或可运行版本发布前，[SECURITY.md](../../SECURITY.md) 中必须提供真实可用的私密漏洞报告渠道。
