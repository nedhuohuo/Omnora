# Omnora 完整 Web 设计

日期：2026-08-08
状态：目标 Web 设计已确认，待按账号—挂载模型实施

> 成员端采用方案 A，受限挂载采用方案 B；详细领域边界见[账号、挂载与内容授权设计](../superpowers/specs/2026-08-08-account-mount-access-design.md)。当前前端仍含 Space 状态的部分属于待迁移实现。

## 1. 目的与范围

本文定义 Omnora 第一版 Web 体验。第一版 Web 包含三个独立但一致的应用壳：

- 成员内容面：成员使用文件、搜索、传输、分享、AI Token 和账户安全能力。
- 管理员控制面：管理员管理系统控制面资源，包括成员、挂载与授权、索引、入口、路由组、治理、审计和备份恢复。
- 公开分享访客面：匿名访客访问一个有效分享范围内的文件或目录。

三者共享 Omnora 品牌、基础组件、主题系统、错误语义和 API 客户端，但导航、权限、可见信息和路由组相互隔离。管理员 Web 并入第一版时，定义为“控制台首版”，不是无限扩张的完整后台系统。

本文不改变[产品需求](../requirements/product-requirements.md)、[领域模型](domain-model.md)、[技术架构](architecture.md)、[安全模型](../security/security-model.md)和[验收标准](../verification/acceptance-criteria.md)中的业务、安全和资源约束。出现冲突时统一按[文档地图的决策优先级](../README.md#决策优先级)裁决，不能用“更严格”改变已确认资源关系或用户能力。

## 2. 设计原则

- 保持轻量：不引入 Office 转换、视频转码、全文检索、OCR、RAG、重型缩略图流水线或常驻分析服务。
- 清晰分权：系统管理员控制系统资源，但默认没有个人目录或共用挂载的内容权限。
- 显式状态：个人文件、共用挂载、协作、只读、索引、离线、身份漂移、权限撤销、对象变化和暴露风险必须使用不同文案、图标和状态色。
- 实时复核：前端只展示能力提示，不能代替后端授权；下载、预览、分享、上传和 AI 读取都必须接受后端实时复核结果。
- 高效扫描：参考夸克网盘的紧凑文件管理效率，但不复制其品牌、会员中心、专有图标、商业视觉资产或无关能力。
- NAS 友好：百万级文件下优先分页、按需渲染和轻缓存；浏览器承担可承担的预览工作，NAS 不做重计算。

## 3. 信息架构

### 3.1 应用壳

| 应用壳 | 路由组 | 登录主体 | 主要入口 |
| --- | --- | --- | --- |
| 成员内容面 | `member_web` | 活跃账号 | 文件、协作、搜索、传输、分享、AI Token、账户 |
| 管理员控制面 | `admin_web` | 初始管理员或普通管理员 | 概览、成员、挂载与授权、索引、网络、路由组、治理、审计、备份 |
| 公开分享访客面 | `share_web` | 匿名分享会话 | 密码验证、分享目录、预览、下载、失效页 |

管理端、成员端、分享、REST、MCP 和 OpenAPI 仍按安全模型作为独立路由组暴露。启用公开分享不得连带启用成员 Web、管理端、REST、MCP 或 OpenAPI。

### 3.2 成员内容面导航

成员端主导航包含：文件、协作、搜索、传输、分享、AI Token、账户。

“文件”使用方案 A：

- “我的文件”直接进入当前账号在默认挂载中的唯一个人目录；默认挂载名称和账号隔离根不暴露给客户端。
- “共用存储”以卡片列出当前账号获权的共用挂载；未授权和零授权挂载不显示。
- 不再显示个人空间、团队空间或空间目录。
- “协作”独立展示“与我协作”和“我发起的协作”；协作目录不混入共用存储。

### 3.3 管理员控制面导航

管理端使用独立控制台导航：

- 概览：资源、风险、入口、挂载健康、任务状态。
- 成员与会话：成员创建、停用、恢复、强制改密、TOTP 状态、会话撤销。
- 挂载与授权：普通/受限挂载、新增、解除、重验证、只读/读写、索引开关和账号 `viewer/editor`。
- 索引与任务：首扫、对账、暂停、恢复、失败重试、批次进度。
- 路由组：管理端、成员 Web、分享、REST、MCP、OpenAPI 独立开关。
- 分享治理：全局分享元数据、状态、访问摘要、撤销。
- Token 治理：Token 元数据、scope 摘要、最后使用、撤销。
- 备份恢复：备份状态、创建备份、恢复向导入口、恢复后重验证入口。
- 审计日志：脱敏查询、过滤、导出、保留状态。

管理端默认不显示个人目录或未授权共用挂载的文件名、目录树、预览、下载或搜索结果。管理员只有收到个人目录协作或挂载内容授权后，才可在成员内容面按该权限访问。普通管理员不能从常规产品入口或被动系统输出直接发现受限挂载的治理信息；已知候选资源的主动占用探测按安全模型处理。

### 3.4 公开分享访客面

公开分享页使用独立轻量壳：

- 不显示成员导航、内部资源名称、挂载名称、账号信息、AI Token 入口或管理入口。
- 支持分享密码、过期、撤销、次数耗尽、目标失效、预览关闭、下载关闭等状态。
- 文件夹分享可浏览授权子树并逐个下载允许文件；首版不提供服务端压缩包。
- “关闭下载”只隐藏直接下载入口，必须提示已预览内容仍可能被保存。
- 分享链接的随机秘密只放在 URL fragment 中。服务端不得从请求路径、查询参数或 Referer 中接收或要求分享秘密。

#### 3.4.1 访客换票状态机

访客进入分享落地页后按下列顺序处理。错误响应对访客不区分令牌错误、密码错误、过期或已撤销，统一进入脱敏失效态；具体原因只用于内部审计与限速主体。

1. **读取秘密**：若地址栏存在 fragment，前端仅在浏览器内存中解析公开 ID 与秘密；若缺少 fragment 或格式无效，显示 `share_secret_missing`，不向服务端提交秘密，也不消耗访问次数。
2. **已有有效分享会话**：若当前浏览器已持有未过期且代际匹配的分享会话 Cookie，直接进入目录/文件视图；页面刷新、目录浏览和预览不重复消耗访问次数。
3. **发起换票**：用 `POST` 提交公开 ID、秘密，以及（若已知需要）分享密码。请求体携带秘密，不得把秘密写入 URL。
4. **需要密码**：若分享设置了密码且本次请求未带密码或密码流程尚未完成，服务端返回 `password_required`，**不**创建分享会话，**不**消耗访问次数。前端展示密码表单；用户提交后回到步骤 3，在同一换票请求中附带密码。
5. **换票成功**：服务端在同一原子事务中建立分享会话并按安全模型预占一次访问次数；前端立即清理地址栏 fragment，再进入目录/文件视图。
6. **换票失败**：包括秘密无效、密码错误、过期、撤销、次数耗尽、目标失效或限速。前端显示统一失效/重试态，**不**创建分享会话，**不**消耗访问次数；密码与令牌失败均计入限速。已读入内存的秘密不得回写到 path、query 或新的历史记录条目。
7. **会话失效后重入**：分享会话过期、代际变化或被撤销后，若 fragment 已被清理，访客必须重新打开原始带 fragment 的分享链接才能再次换票；重新成功换票会再次消耗访问次数。

## 4. 成员端页面与流程

### 4.1 认证与账户安全

页面包含登录、TOTP 挑战、恢复后强制改密、账户安全和活跃会话。登录、TOTP 和分享密码错误不得枚举账号或凭证是否存在。会话过期、账号停用、密码重置、TOTP 重置和入口 audience 不匹配必须进入明确的重新登录流程。

账户安全页支持：

- 修改密码，并可选择同时撤销 Token 与分享。
- 启用、重置和停用成员 TOTP。
- 查看并撤销自己的活跃会话。
- 管理主题偏好：跟随系统、浅色、深色。

### 4.2 文件工作区

文件工作区首版支持“我的文件 / 共用存储”切换、挂载卡片、目录面包屑、列表/网格视图、搜索筛选、选择和批量操作。排序、常驻详情面板和精确滚动位置恢复属于体验增强，不作为第一版发布阻断项。

首版必须支持：

- 浏览目录和文件。
- 上传文件与目录，新建目录。
- 复制、移动、改名、批量处理。
- 删除者使用自己的个人回收站；单个文件不超过 200 MB 时可以进入回收站。
- 超过 200 MB 的文件不显示普通“移到回收站”，只能在明确永久删除二次确认后删除。
- 目录或批量选择中只要包含超过 200 MB 的文件，整批就不能移到回收站；界面引导用户拆分选择，或在展示影响摘要后明确确认永久删除。
- 恢复时优先写回原位置并重新检查当前 `editor`、挂载在线状态和路径边界；原位置不可写或已失权时，恢复到删除者的“我的文件/从回收站恢复”，且不得覆盖同名对象。
- 只读挂载禁用写操作并解释原因。
- 跨挂载复制与移动的部分完成、重试和人工清理入口。

列表视图是通用目录默认视图；网格视图可手动切换。视图偏好按“账号 + 内容来源 + 挂载/协作”记忆。排序偏好和目录滚动位置记忆可作为后续体验增强，不覆盖搜索结果等虚拟视图。

### 4.3 搜索

搜索支持按文件名、扩展名、类型、大小、修改时间和所在目录筛选。成员 Web 全局搜索覆盖“我的文件 + 获权且已索引共用挂载 + 当前有效的收到协作”。协作结果显示来源账号和“协作”标记，按对象去重；“我发起的协作”不重复加入。搜索结果只在当前账号已获权且可发现的挂载集合内列出因索引关闭、暂停、离线或未完成首扫而被排除的挂载；未授权和不可发现的受限挂载不出现。空结果不能暗示已搜索全部挂载。

打开搜索结果、下载、分享或预览前必须实时回源复核。对象已变化或不存在时显示独立状态，并允许返回搜索结果继续操作其他对象。

### 4.4 传输中心

传输中心首版覆盖上传、跨挂载复制和跨挂载移动。普通下载可以继续使用浏览器原生下载入口，但必须由后端 Range 和流式下载测试保证固定内存、权限复核和取消下载计数语义。全局底部传输条展示当前任务，完整中心展示历史、失败原因和可恢复状态。

发布阻断状态包括上传中、复制中、移动中、提交中、失败、重试、取消、冲突、配额不足、磁盘安全水位不足、权限中途撤销和挂载转只读。排队、任务完成等基础状态应覆盖在传输中心组件测试中；暂停等待网络、下载中等纯展示专项可作为后续体验增强。耗时任务不能只依赖 Toast；Toast 只用于即时反馈。

### 4.5 预览与详情

详情面板可在桌面常驻，在平板和移动端作为抽屉，但不作为第一版发布阻断项。全屏预览关闭后必须恢复目录、过滤和选择；精确滚动位置恢复可作为后续体验增强。

首版预览规则：

| 类型 | 行为 |
| --- | --- |
| 图片 | 浏览器直接显示；目录缩略图默认不生成、不请求，用户启用缩略图视图后仅对可见项目懒加载 |
| PDF | 浏览器端 PDF.js 预览 |
| 纯文本 | 限制读取大小后显示 |
| Markdown | 清洗危险内容后渲染 |
| 音频、视频 | 仅播放浏览器原生支持编码 |
| Word、Excel、PowerPoint | 不预览，只显示信息和下载 |
| 其他格式 | 显示信息和下载 |

预览失败不得影响有下载权限的用户下载原文件。

### 4.6 我的分享

个人文件只有所有者可以创建公开分享；共用挂载默认允许 `editor` 创建，具有该挂载治理权的管理员可以关闭公开分享；收到的协作不显示公开分享入口。创建表单包含目标对象、密码可选、有效期、预览开关、下载开关、访问次数上限和下载次数上限。

创建成功后只展示一次可复制的完整分享 URL。该 URL 必须把公开 ID 与随机秘密放在 `#` fragment 中，形态示例：

`https://<对外主机>/s/<可选公开路径提示>#<public_id>.<secret>`

约束：

- 一次性展示的可复制内容必须是上述带 fragment 的完整 URL；可以同时提供“仅复制秘密”的次要操作，但不能替代完整 URL。
- 禁止生成或展示把秘密放在 path、query、`?token=`、`?key=` 或基础路径段中的链接。
- 关闭一次性展示后，列表与详情只能显示公开 ID、目标摘要和状态，不能再次显示完整秘密或可还原秘密的完整 URL。
- 复制到剪贴板的内容必须与展示内容一致，并保持 fragment。

我的分享页展示分享状态、目标摘要、能力、次数、过期时间、访问记录摘要、修改入口和撤销入口。分享状态包括 active、expired、revoked、exhausted、creator_lost_permission、target_moved_or_replaced。下载次数在创建下载票据时预占，网络中断不退还次数，UI 必须说明该语义。

### 4.7 协作

协作页分为“与我协作”和“我发起的协作”。所有者可以从“我的文件”的个人根或任意子目录发起协作，为每个活跃接收账号选择 `viewer/editor`。同一接收账号的父子目录授权不能重叠。协作不会创建挂载。

分享整个个人根时，确认界面必须醒目提示“当前内容和未来新增到个人根的内容都会对接收者可见”。收到的协作显示来源账号、目录名称、权限、状态和打开入口；发出的协作显示接收人、权限、边界和撤销入口。

协作 `editor` 可以修改根内内容，但不能改名、移动或删除协作根。收到的协作提供“保存到我的文件”，其语义固定为复制；不提供匿名公开分享、再授权第三人或移出所有者目录的跨边界移动。

### 4.8 AI Token

AI Token 页支持创建、查看元数据、查看最近使用摘要和撤销。创建表单包含名称、有效期、资源来源、挂载/个人目录、目录边界、scope、REST/MCP 用途和上传能力，不再选择 Space。可选择动态的“当前账号全部内容源”，覆盖自己的个人目录和当前获权共用挂载；收到的协作不进入 Token boundary。AI Token 是绑定成员账号的受限 PAT，但本页只管理面向 AI/REST/MCP 的受限 Token，不提供通用 PAT 管理入口。Token 默认只读；上传、回收站和分享必须显式授予 scope；迁移后 catalog 标记的移动、删除、回收站清理、分享变更和覆盖已有文件内容等高风险工具还必须逐次完成 MCP MRTR，具体数量不在 Web 文档中固定。

明文 Token 只展示一次。关闭创建结果后，只能查看公开 ID、名称、scope 摘要、创建时间、过期时间、最后使用、状态和撤销入口。

## 5. 管理员控制台页面与流程

### 5.1 初始化与管理员安全

首次初始化通过一次性初始化凭证创建首个管理员。管理员完成密码设置前，只能访问初始化步骤，不能配置公网、分享、Token 或挂载。初始化完成后，网络初始化路由永久不可用。

> **产品决策（冻结）：管理员与成员的两步验证（TOTP）均为可选。** 登录成功后不得把管理员锁进强制 TOTP 登记页；账号安全页提供与成员相同的启用/停用流程。后续设计与实现不得再引入“管理员必须启用 TOTP”。

管理员敏感操作需要近期重新认证；若该账号已启用 TOTP，重新认证还需验证码。唯一管理员密码丢失，或已启用 TOTP 后无法使用验证器时，恢复流程必须要求 NAS 本地控制权，不能提供远程无鉴权重置。

### 5.2 系统概览

概览页展示：

- 入口状态：HTTP 监听、反向代理提示、路由组开关。
- 资源状态：内存、任务队列、SQLite/WAL、磁盘安全水位。
- 挂载健康：正常、只读、离线、身份漂移、身份不可验证、冲突。
- 索引健康：运行、暂停、未加入、首扫未完成、失败。
- 风险提醒：公网管理端、未加密 LAN、长期 Token、异常分享、备份过期。

概览页不得展示个人目录、未获权共用挂载或受限挂载的文件名、目录结构或内容。普通管理员的概览也不得通过数量和健康摘要泄露受限挂载存在。

### 5.3 成员与会话

管理员可以创建、停用、恢复或删除普通成员账号，查看 TOTP 启用状态，强制改密，撤销指定账号全部会话；恢复只适用于停用账号，删除为不可逆身份删除。任一管理员可以把成员提升为普通管理员，并降级、停用、恢复或删除其他普通管理员；普通管理员不能操作初始管理员，任何管理员都不能操作当前登录的自己。管理员发起的密码/TOTP 重置或账号恢复视为凭证可能泄露，必须撤销该账号旧会话、PAT/AI Token 和活动分享。

成员列表只展示账号、安全状态、个人目录容量摘要和最近安全事件，不展示个人文件名或目录。新增账号成功时，其个人目录必须已经可用；失败时不能显示成可登录账号。删除账号的确认界面明确提示“账号访问和派生能力立即失效，但个人目录与物理文件保留”。

### 5.4 管理员内容访问边界

管理员控制面不展示个人目录或未获权共用挂载的文件名、目录或内容。个人目录访问只走所有者发起的目录协作，共用挂载访问只走 `viewer/editor`；账号恢复、管理员身份和挂载治理权限不会自动授予内容权限。

### 5.5 挂载与授权管理

普通挂载对所有管理员可见并可治理。受限挂载只对初始管理员显示；普通管理员直接请求其管理路由时按 `404` 处理。普通管理员即使获得受限挂载内容权限，也只能从成员内容面打开文件，不显示受限标记、授权名单或治理操作。

挂载详情支持按账号配置 `viewer/editor`，并允许授权列表为空。创建者和管理员不会被自动加入内容授权。

普通/受限治理类型在创建时固定，创建后不提供切换开关。需要改变时，解除后用新的挂载 ID 重新注册同一物理路径。

### 5.6 挂载管理

新增挂载必须显式选择：

- 容器内已预映射路径。
- 显示名称。
- 只读或读写模式。
- 是否加入索引。
- 普通或受限治理类型；受限选项仅初始管理员可见。
- 可为空的账号 `viewer/editor` 授权。

共用挂载只接入已映射的外部 NAS 目录；界面不提供“创建托管共用挂载”。活跃挂载显示名称忽略大小写全局唯一。

默认个人挂载不出现在普通挂载列表，也不提供删除、主动停用、改根、读写模式或索引开关。它固定为 `read_write` 并使用按账号根裁剪的个人索引；底层离线、不可写、身份漂移、个人目录丢失或初始化部分失败时显示为 `unavailable`。只有初始管理员看到专用修复入口，用于核对身份和账号映射、恢复原目录或明确创建替代目录、处理孤立准备状态；界面不得静默创建空目录或把删除账号目录绑定给新账号。

Web 不能让用户误以为可以直接选择 NAS 任意宿主绝对路径；宿主机目录必须先通过容器编排映射给 Omnora。系统必须拒绝相同路径、双向父子路径、符号链接、magic link、bind alias、bind 源父子关系和身份不可验证挂载，错误码 `mount_identity_unverifiable` 必须有明确解释。首版不提供管理员绕过。

选中外部目录后直接注册该目录本身，不能提示或创建 `<space-id>` 等子目录。解除挂载要求精确输入当前显示名称，提示只移除 Omnora 注册和派生授权、不删除服务器真实文件，并显示 `dataDeleted: false`。以后重新注册同一路径会得到新的挂载 ID，旧授权不会恢复。

挂载离线、身份漂移、身份不可验证、冲突、权限不足或变为只读时，管理端展示原因并自动停用不安全能力。

### 5.7 索引与后台任务

索引按挂载独立启用、暂停、恢复和关闭。索引管理页展示首扫进度、上次对账、当前批次、失败原因、重试状态和被搜索排除原因。

UI 必须体现低功耗 NAS 约束：全局后台任务单并发、低优先级批次、可暂停、可恢复、批次让出。不要展示会暗示高并发扫描、全文索引或内容分析的能力。

### 5.8 路由组

路由组页管理管理端、成员 Web、分享、REST、MCP 和 OpenAPI 是否暴露。系统不得根据来源 IP、私网地址、Host 或客户端提交的转发头自动判断公网或局域网。公网管理端默认关闭；启用时必须明确提示风险并要求近期重新认证。

路由组页独立控制管理端、成员 Web、公开分享、REST、MCP 和 OpenAPI。启用一个路由组不得隐式开启其他路由组。

### 5.9 分享与 Token 治理

管理员只能查看其治理范围内分享的安全元数据并撤销分享；个人目录分享只展示不含路径、正文或秘密的安全摘要，受限挂载分享和策略只对初始管理员可见。所有管理员可以查看账号 Token 的通用安全元数据、状态、创建者、scope 摘要、过期时间和最后使用并撤销 Token，但普通管理员无权查看的资源边界必须统一脱敏，不能通过字段或数量差异泄露受限挂载。

管理员不能查看分享密码、分享密钥、明文 Token、密码、TOTP 密钥或文件正文。分享和 Token 列表必须脱敏，不能泄露个人目录、未授权挂载或受限挂载路径。

### 5.10 审计、备份与恢复

审计页支持按时间、主体、入口、事件类型、对象类型和结果过滤，支持脱敏导出。审计记录不得包含密码、明文 Token、分享密钥、文件正文或未脱敏分享 URL。

备份恢复页第一版覆盖状态、创建备份、恢复向导入口和恢复后重验证入口。从旧备份恢复后，旧会话、Token、公开分享、下载票据和上传会话全部失效；成员首次登录前必须重设密码。普通挂载可由任一管理员重新验证，受限挂载和默认个人挂载只由初始管理员处理。

完整恢复演练自动化、复杂审计报表、资源历史趋势和诊断包深度分析可作为后续增强，不阻塞控制台首版。

## 6. 响应式与移动端边界

| 断点 | 成员端 | 管理端 |
| --- | --- | --- |
| `>= 1280px` | 一级侧栏、二级侧栏和详情面板可常驻 | 控制台侧栏和主内容常驻 |
| `1024-1279px` | 一级导航收窄，详情使用覆盖抽屉 | 控制台侧栏收窄，复杂表格可横向容器滚动 |
| `768-1023px` | 二级导航横向滚动，详情和预览覆盖显示 | 概览、告警、列表可用，复杂编辑引导到桌面 |
| `< 768px` | 底部导航，支持浏览、搜索、上传、传输、预览、下载、分享和撤销 Token | 只覆盖概览、告警、暂停任务、撤销风险分享/Token、查看部署入口提示 |
| `< 480px` | 工具栏只保留上传、搜索和更多，文件列表隐藏次要列 | 不提供新增挂载、恢复演练、复杂授权编辑 |

管理员移动端不是完整后台。移动端只覆盖概览、告警、任务暂停、状态查看和撤销风险分享/Token 等风险处置动作。新增挂载、备份恢复、复杂授权编辑和批量治理优先桌面完成。

## 7. 组件与前端数据流

前端按业务能力组织：

- `features/auth`：登录、TOTP、强制改密、会话。
- `features/files`：我的文件/共用挂载浏览、文件列表、详情、预览。
- `features/search`：搜索表单、结果、排除挂载说明。
- `features/transfers`：上传、跨挂载任务、传输中心；普通下载入口保留在文件、搜索和分享流程中，由 Range 与流式下载测试覆盖。
- `features/member-shares`：成员分享创建、列表、访问记录摘要和撤销。
- `features/share-portal`：公开分享密码交换、访客目录、预览、下载和失效页。
- `features/tokens`：AI Token 创建、列表、撤销。
- `features/account`：账户安全、主题、活跃会话。
- `features/admin`：控制台概览、成员、挂载与授权、索引、网络、治理、审计、备份。
- `shared`：布局、表格、抽屉、对话框、Toast、状态徽标、文件图标、错误呈现、可访问交互组件。

React Router 负责路由、应用壳切换和登录态守卫。TanStack Query 负责服务端状态、缓存、分页、失效和请求取消。OpenAPI 生成客户端是 REST 类型来源；前端不手写重复接口类型。

前端不能把隐藏按钮当成授权。任何操作按钮点击后都必须接受后端结构化错误，并按错误类型更新菜单、详情、列表和任务状态。

## 8. 状态与错误语义

全局必须区分：

- 浏览器断网。
- HTTP 未使用 TLS 时的浏览器安全提示。
- 会话过期或撤销。
- 账号停用。
- 路由组未暴露。
- `member_web_not_exposed`。
- 入口信任失败。

文件与搜索必须区分：

- 空目录。
- 无权限。
- 只读挂载。
- 挂载离线。
- 挂载身份漂移。
- 挂载身份不可验证。
- 索引关闭。
- 索引暂停。
- 首扫未完成。
- 对象已变化或不存在。
- 配额或磁盘水位不足。

分享与 Token 必须区分：

- active。
- expired。
- revoked。
- exhausted。
- creator_lost_permission。
- target_moved_or_replaced。
- scope_no_longer_valid。
- plaintext_shown_once。
- share_secret_missing。
- password_required。

错误呈现遵循“可解释、可恢复、不过度打扰”：阻断式风险用页面横幅或对话框；任务类状态保留在传输中心或管理任务页；即时成功失败可用 Toast。

## 9. 无障碍与键盘

第一版 Web 不声明完整 WCAG 合规认证，但以 WCAG 2.2 AA 的关键可执行项作为首版工程门槛：

- 正文对比度至少 `4.5:1`，控件边界、焦点和状态图形至少 `3:1`。
- 所有图标按钮必须有可访问名称、可见焦点和悬浮提示。
- 文件列表使用 roving tabindex：方向键移动焦点，`Home/End` 到边界，`PageUp/PageDown` 翻页，`Space` 切换选择，`Enter` 打开。
- `Ctrl/Cmd+A` 仅在文件区域获得焦点时选择当前已加载结果。
- `Shift+F10` 或菜单键打开对象菜单。
- `Escape` 按层级关闭菜单、抽屉、对话框和预览，不丢失选择或传输状态。
- 对话框捕获焦点，关闭后恢复触发点。
- 移动端触控目标至少 `44x44px`，相邻目标间距至少 `8px`。
- 遵守 `prefers-reduced-motion`，非必要位移和缩放动画可关闭。

大量文件结果不得只依赖无限滚动；必须提供键盘和读屏可访问的加载更多或分页机制。

## 10. 视觉方向

Omnora Web 采用“安静、密集、清晰”的 NAS 工作台风格：

- 成员端偏文件管理效率：紧凑列表、清晰状态、低干扰操作条。
- 管理端偏控制台：风险优先、状态明确、危险操作更克制。
- 分享页偏轻量可信：少导航、少干扰、聚焦被分享对象。
- 默认跟随系统主题，允许手动浅色或深色并记忆偏好。
- 主品牌色使用克制的青绿色，管理风险使用琥珀色，危险操作使用红色；颜色不能作为唯一状态表达。

不使用夸克网盘品牌、会员入口、Logo、图标、专有文案、BT 下载、云备份或非需求能力。

## 11. 测试策略

### 11.1 前端单元与组件测试

- 权限矩阵下的按钮可见性、禁用原因和后端拒绝后的状态刷新。
- 文件列表、网格、选择模型、批量操作入口和视图偏好；排序偏好和滚动恢复作为体验增强回归测试，不列为发布阻断。
- 搜索排除挂载提示和对象变化错误。
- 分享创建、次数语义、撤销和失效状态。
- Token 明文仅展示一次、scope 摘要和撤销。
- 管理端高风险操作确认、近期重新认证和脱敏展示。

### 11.2 浏览器端到端测试

验收视口至少覆盖 `375x667`、`768x1024`、`1024x768` 和 `1440x900`。

端到端流程覆盖：

- 登录、TOTP、强制改密、会话撤销。
- 成员浏览、搜索、上传续传、Range 下载、预览、Office 下载。
- 创建分享时一次性展示带 `#fragment` 的完整 URL，且 path/query 不含秘密。
- 访客无 fragment、有密码、无密码、密码错误、过期、撤销、次数耗尽；换票成功后地址栏 fragment 已清理；`password_required` 与换票失败均不消耗访问次数；成功建立会话后刷新不重复计数。
- 创建 AI Token、明文一次性展示、撤销。
- 管理员创建成员并验证个人目录自动可用，添加普通挂载、配置独立账号授权、启停索引、解除挂载、配置入口和控制路由组；初始管理员还需验证受限挂载治理，解除挂载后服务器真实文件仍被保留。
- 审计脱敏、备份恢复状态和外部挂载重验证入口。

### 11.3 安全与资源验收

Web 验收必须覆盖：

- 无显式内容授权的管理员不能看个人目录或共用挂载内容。
- 单 HTTP 入口下的路由组开关、Host/Origin 校验和浏览器安全提示。
- 反向代理拓扑下的分享、成员 Web、Range、流式下载、WebSocket 和 MCP 长连接提示。
- 分享秘密不出现在 path、query、Referer、应用日志或代理默认访问日志；换票后浏览器地址栏不再保留 fragment。
- 百万级元数据下文件列表和搜索使用分页，不产生页面级横向滚动或明显卡顿。
- 可预览能力失败不阻止下载。
- 缩略图、PDF.js 和媒体播放器按需加载，不常驻拖高内存。

## 12. 首版取舍

纳入第一版：

- 成员完整工作台。
- 管理员控制台首版。
- 公开分享访客页。
- REST、MCP、OpenAPI 暴露开关的 Web 配置。
- 移动端成员核心流程和管理员风险处置。

不纳入第一版：

- Office 在线预览或编辑。
- 服务端视频转码、OCR、全文索引、向量检索和内置 AI 问答。
- WebDAV、S3、SMB 网关。
- 跨 NAS 同步、多节点集群、插件市场、原生移动端和桌面同步客户端。
- 管理端复杂报表、资源历史趋势、完整诊断包分析和高级批量授权工具。

## 13. 已确认决策

- Web 第一版包含成员端、管理员控制台和公开分享页。
- 管理员控制台是控制面，不默认授予个人目录或挂载内容访问权。
- 初始管理员与普通管理员对普通挂载日常治理相同；受限挂载仅初始管理员可从治理控制面直接发现和治理，主动候选资源占用探测例外按安全模型处理。
- 任一管理员可以把成员提升为普通管理员，停用、恢复或删除普通成员，并降级、停用、恢复或删除其他普通管理员；普通管理员不能操作初始管理员身份，任何管理员不能操作当前登录的自己。
- 管理员移动端只做必要治理动作，复杂配置桌面优先。
- 文件 UI 采用方案 A：“我的文件 + 获权共用存储”，协作使用独立入口，不显示个人/团队空间。
- 系统自适应主题，允许手动浅色或深色并记忆偏好。
- 列表为通用目录默认视图，视图偏好按位置记忆。
- Office 文件不预览，只走下载逻辑。
- 首版保持低功耗 NAS 资源边界，不引入重型内容处理服务。
