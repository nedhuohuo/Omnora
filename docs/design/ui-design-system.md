# Omnora UI 设计规范

日期：2026-08-07
状态：已生效
适用范围：`web/src/` 下全部前端（成员端、管理端、公开分享页）

本文是 Omnora Web 界面的**唯一视觉权威**。任何新增组件、样式修改、主题调整都必须遵循本文定义的令牌与规则；与本文冲突的代码视为缺陷，应在修改相关功能时顺手修正。

## 1. 设计原则

- **安静、密集、清晰**：NAS 工作台风格，紧凑列表、低干扰操作条，不做花哨装饰。
- **令牌驱动**：颜色、字号、间距、圆角、阴影一律通过 CSS 变量（设计令牌）引用，禁止在组件 CSS 中出现未经令牌定义的硬编码值。
- **主题双轨**：所有颜色必须同时提供浅色（默认）与深色（`[data-theme="dark"]`）两个取值，由 `:root` 与 `[data-theme="dark"]` 中的同名变量切换。
- **颜色不唯一**：状态表达不能只靠颜色，必须配合文字、图标或符号。
- **保持轻量**：不引入组件库、图标库或 CSS 框架；样式以手写 CSS 变量 + 语义类为主。

### 2.3 语义色

语义色统一三件套（背景/边框/文字），禁止在组件中硬编码 `#fff9ea` 之类的字面量。

| 语义 | 令牌前缀 | 浅色 bg / border / text | 深色 bg / border / text | 典型用途 |
| --- | --- | --- | --- | --- |
| 成功 | `--success-` | `#f1fbf5` / `#b9e4cc` / `#1f7a45` | `#122419` / `#1f4a33` / `#6fd8a0` | 操作成功、已暴露 |
| 警告 | `--warning-` | `#fff9ea` / `#f0d5a6` / `#925d00` | `#241d0e` / `#4a3a14` / `#e2bd6d` | 只读提示、风险提示 |
| 危险 | `--danger-` | `#fff5f3` / `#f4c8c2` / `#c43c3c` | `#2b1615` / `#5a2b28` / `#e06969` | 错误提示、危险操作 |
| 信息 | `--info-` | `#f2f7ff` / `#cfe0f7` / `#3d6c9e` | `#101d2b` / `#1f3a55` / `#8fb7de` | 搜索范围提示、说明 |

对应变量：`--{prefix}-bg`、`--{prefix}-border`、`--{prefix}-text`。危险操作按钮用 `--danger`（= 危险文字色）。

**状态点**（`--status-*`）：`ok #1f9d55`、`warn #d98a1f`、`danger #c43c3c`、`info #1677ff`、`muted #a2acb9`，深色不另设，沿用同一色值保证辨识度。

## 3. 字体

### 3.1 字体栈

| 令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--font-sans` | `"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Helvetica Neue", sans-serif` | 全部界面文字 |
| `--font-mono` | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | 代码块、路径、连接串 |

`html` 根元素设置 `--font-sans`，组件不单独设置字体族（预览文本等特殊场景用 `--font-mono`）。

### 3.2 字号阶梯

所有字号必须取自下表，禁止出现阶梯之外的中间值（如 10px、19px、23px）。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--text-xs` | 11px | 辅助标签、徽标、时间戳 |
| `--text-sm` | 12px | 次要文字、表格次列、小按钮 |
| `--text-md` | 13px | **默认正文**：按钮、表格主体、表单标签、提示条 |
| `--text-lg` | 14px | 强调正文、文档辅助内容 |
| `--text-doc` | 15px | 文档中心正文（段落、列表、FAQ）——与普通界面区分 |
| `--text-xl` | 16px | 小节标题（h3）、账户区块标题 |
| `--text-2xl` | 17px | 章节标题（h2，文档中心） |
| `--text-3xl` | 18px | 弹窗标题（h2） |
| `--text-4xl` | 22px | 页面标题（h1） |
| `--text-display` | 28px | 概览大数字 |

### 3.3 字重与行高

- 常规正文 `font-weight: 400`（默认）；强调用 `600`；导航选中/按钮 `700`；品牌 Logo `750`。
- 行高：正文 `1.5`，文档正文 `1.55–1.6`，紧凑表格/按钮 `1`。
- 品牌 Logo 字号固定 19px（`--text-brand`），Logo 方块内首字母字号固定 15px，不随阶梯调整。

## 4. 间距

### 4.1 布局间距阶梯（4px 基准）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--space-1` | 4px | 元素间微距 |
| `--space-2` | 8px | 紧凑间隙、表单内间隙 |
| `--space-3` | 12px | 常规间隙、紧凑卡片内边距 |
| `--space-4` | 16px | 卡片内边距、侧栏内边距 |
| `--space-5` | 20px | 弹窗内边距、区块间距 |
| `--space-6` | 24px | 顶栏内边距、内容区间距 |
| `--space-7` | 32px | 内容区水平内边距 |
| `--space-8` | 40px | 大面积留白 |

布局上的 `gap` / `margin` / `padding` 必须从本阶梯取值，禁止 9、11、13、14、18、21、23、25、26、28、30 等中间值。

### 4.2 控件内边距

控件（按钮、输入框、下拉）内边距允许以下固定值，不属于布局阶梯：

- 按钮/输入框：水平 `10–12px`，高度 `34px`（默认）/ `37px`（表单）/ `39px`（登录主按钮）。
- 小按钮（徽标操作）：水平 `8–9px`，高度 `24–28px`。
- 紧凑提示条：`9px 10–11px`。

## 5. 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-xs` | 4px | 徽标、子元素按钮（分段控件内部） |
| `--radius-sm` | 5px | 按钮、输入框、下拉、小面板、提示条 |
| `--radius-md` | 6px | 卡片、表格容器、文件网格项 |
| `--radius-lg` | 8px | 大面板（登录、分享面板）、预览对话框 |
| `--radius-full` | 999px | 状态点、圆形元素 |

禁止使用 7px 等中间值。

## 6. 分割线

- 分割线一律 `1px` 实线，颜色从边框四档取：面板分隔用 `--border`，控件边框用 `--border-strong`，表格行线/卡片内分隔用 `--border-soft`，卡片描边用 `--border-card`。
- 同层元素之间用 `--border-soft`，跨层区域用 `--border`。
- 禁止使用 `--border` 以外的自定义灰色边框色值。

## 7. 阴影

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-sm` | `0 1px 2px rgb(37 58 85 / 0.08)` | 分段控件选中项 |
| `--shadow-md` | `0 10px 24px rgb(37 58 85 / 0.12)` | 下拉菜单、路径建议 |
| `--shadow-lg` | `0 18px 46px rgb(37 58 85 / 0.12)` | 登录/分享面板、传输浮层 |
| `--shadow-xl` | `0 22px 54px rgb(17 34 55 / 0.25)` | 模态框 |

## 8. 图标

项目不引入图标库，统一采用文字/符号方案：

### 8.1 文件类型图标

- 实现：`web/src/member/FileTypeIcon.tsx` 内联 SVG 组件（零依赖、离线可用），图标经 `currentColor` 继承主题令牌颜色，**禁止**引入字体图标库或 CDN 图标服务。
- 形态：`26 × 23px` 圆角小方块（`--radius-xs`），内部 15px 线性图标（16 viewBox、1.5px 描边、圆角端点）。
- 分类：目录（文件夹）、图片、视频、音频、文档、压缩包、代码、通用文件共 8 类，由 `fileIconType(kind, name)` 按扩展名映射（大小写不敏感），未知扩展名回退通用文件图标。
- 配色：文件类用蓝色系，目录用琥珀色系（见 2.4），图标 `stroke: currentColor` 自动跟随。
- 用途：文件列表、网格、分享选择器统一复用 `.member-file-icon` 与 `FileTypeIcon` 组件；新增文件列表场景必须复用该组件，不得另写图标。

### 8.2 操作符号

- 关闭/删除行内操作：`×`（`&#215;`），必须有 `aria-label` 与 `title`。
- 符号类按钮字号按上下文取 `--text-sm` 或 `--text-md`，禁止使用 emoji 作为操作图标。

### 8.3 状态点

- 形态：`8 × 8px` 圆形（`--radius-full`），颜色从 `--status-*` 取值。
- 必须与文字/徽标同现，禁止单独用颜色表达状态。

## 9. 控件规范

### 9.1 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 `.member-primary` | `--accent` 底、白字、`--radius-sm`、悬停 `--accent-hover`、禁用 `opacity .55` |
| 默认按钮 | `--surface` 底、`--border-strong` 边框、`--text-muted` 字、悬停边框/文字变 `--accent` |
| 危险按钮 `.member-modal-danger` | `--danger` 底、白字 |
| 文字按钮（列表内操作） | 无边框、`--accent-text`、悬停下划线 |

- 按钮字号统一 `--text-md`（13px），`line-height: 1`，`min-height` 见 4.2。
- 聚焦可见性：`outline: 3px solid rgb(22 119 255 / 0.36)`、`outline-offset: 2px`（全局定义于 `styles.css`，禁止覆盖）。

### 9.2 输入框与表单

- 输入框：`height: 37px`、`padding: 0 10px`、`--border-strong` 边框、`--radius-sm`、底色 `--input-bg`。
- 表单 label：`--text-md`、`--text-muted`，与控件间距 `--space-2`（gap 7px 归一到 8px）。
- 复选框：`16 × 16px`、`accent-color: var(--accent)`。

### 9.3 表格

- 表头：`height: 38px`、`--text-sm` 字号 `600` 字重、`--text-faint` 色、底线 `--border-soft`。
- 行：`height: 50–52px`、`--text-md`、行间线 `--border-soft`、悬停 `--surface-hover`。
- 管理端操作列按钮同 9.1 文字按钮。

### 9.4 卡片与面板

- 卡片：`--surface` 底、`--border-card` 边框、`--radius-md`、内边距 `--space-4`。
- 表单容器：`--surface-2` 底、`--border-card` 边框、`--radius-md`、内边距 18px（归一到 `--space-4`）。
- 提示条（语义框）：`--radius-sm`、内边距 `9px 11px`、配色取 2.3 语义三件套，字号 `--text-md`。

### 9.5 模态框

- 宽度 `min(380px, 100%)`（管理表单 `min(640px, 100%)`）、内边距 `--space-5`、`--radius-md`、`--shadow-xl`、遮罩 `--backdrop`。
- 标题 `--text-3xl`（18px），标题与内容间距 `--space-4`（gap 18 归一到 16px）。
- 底部操作区右对齐、间距 `--space-2`。

## 10. 焦点与可访问性

- 键盘焦点：全局 `:focus-visible` 蓝环（见 9.1），禁止用 `outline: none` 静默移除。
- 图标按钮必须有 `aria-label`；颜色不单独表达状态。
- 对比度门槛：正文 `4.5:1`，控件边界与状态图形 `3:1`（以 WCAG 2.2 AA 为工程门槛）。
- 触控目标不小于 `44 × 44px`，相邻目标间距至少 `--space-2`。

## 11. 响应式断点

| 断点 | 规则 |
| --- | --- |
| `900px` | 顶栏换行、侧栏横向滚动、内容内边距 `20px 15px` |
| `700px` | MCP 状态/预设网格 `2` 列 |
| `640px` | Token 边界行单列 |
| `560px` | 隐藏表格次要列、工具栏收窄 |
| `480px` | 状态网格单列 |

内容区桌面内边距 `25px 30px`（归一为 `--space-6 --space-7`），底部留白 `110px`。

## 12. 规范执行规则

- **新增颜色必须走令牌**：任何新色值先判断是否可复用现有令牌；新增语义色须同时补充浅/深两档并更新本文。
- **禁用值清单**：字号 10/19/23px、圆角 7px、间距 9/11/13/14/18/21/23/25/26/28/30px、硬编码语义色（`#fff9ea`、`#f0d5a6`、`#925d00`、`#f4c8c2`、`#fff5f3`、`#f1fbf5`、`#b9e4cc`、`#1f7a45`、`#cfe0f7`、`#f2f7ff`、`#3d6c9e` 等）。
- **主题必须双轨**：新增颜色不在深色模式提供对应值时，视为规范违约。
- **样式放对文件**：全局令牌只存在于 `styles.css`；组件样式按面分文件（成员/管理 `member-files.css`、分享 `share-portal.css`）。
- **文档同步**：本文与代码冲突时，以代码实际行为为准修正本文，或按本文修正代码——不允许两边长期不一致。
